# TS Planner 0.4.0 — current build

Updated September 25, 2026. See [release notes](RELEASE-0.4.0.md) for features, verification and limitations.

The local planner, seven themes, bundled fonts, recurrence, checklists, inbox, calendar views, backup/restore and scheduling are implemented. This release adds Spanish interface support, calendar file import/export and real locally tested AI suggestions. All 48 tests, catalog coverage and production build pass. Windows packages compile.

Public launch is not complete: Supabase/Google/GitHub owner configuration is missing. Live Gmail, Family, cross-device sync and Google Calendar tests remain pending. Native OS reminder delivery and the updated Windows launch need normal desktop verification. No paid service was activated.

Use release/TS-Planner-Windows-0.4.0. The optional model is in the separate ../TS-Planner-Local-AI folder. Keep the full folder together. Export a backup and quit an older planner from its tray menu before opening the new release.
